# MathBuilder — веб-версия

Интерактивная веб-версия учебного приложения **LEGO® Education MoreToMath** (MathBuilder).
Работает в браузере без установки и без сборки — обычные HTML/CSS/JS.

**Сайт:** https://android-studio-cyber.github.io/mathbuilder-web/

## Что внутри

- **16 активностей** и **155 заданий** — данные автоматически извлечены из оригинальных файлов `mtmml.xml`.
- **Полная русская локализация** (и английская): тексты заданий, названия активностей, интерфейс.
- **Реальные изображения** из оригинального приложения: обложки активностей, аватары персонажей, картинки-образцы моделей и иконки кирпичиков.
- **Поля ответов** повторяют структуру оригинала: числа, текстовые метки (`+`, `=`) и картинки.
- **Навигация по заданиям**: «Назад», «Повтор» (озвучивание текста), «Готово», «Далее»; работают стрелки клавиатуры.
- **Сохранение прогресса** в браузере (localStorage): ответы и отметки о выполнении не теряются после перезагрузки.
- **Фильтр по темам**: животные и насекомые, на улице, спорт, еда.
- **Просмотр образцов** — клик по картинке открывает её в полном размере.
- Адаптивная вёрстка для планшетов и телефонов.

## Структура проекта

```
index.html            — разметка приложения
css/style.css         — стили
js/translations.js    — все строки RU/EN + метаданные активностей
js/data.js            — задания и карта изображений (генерируется автоматически)
js/app.js             — логика приложения
assets/img/           — изображения из оригинального приложения
tools/gen_data.py     — генератор js/data.js и assets/img из MathBuilder/AppResources
```

## Обновление данных

Если изменились исходные файлы `MathBuilder/AppResources`, пересоберите данные:

```powershell
python tools\gen_data.py
```

Скрипт заново создаст `js/data.js` и скопирует только используемые картинки в `assets/img`.

## Локальный запуск

Достаточно открыть `index.html` в браузере, но для корректной работы с изображениями
лучше поднять простой локальный сервер:

```powershell
python -m http.server 8123
```

Затем открыть http://127.0.0.1:8123/
