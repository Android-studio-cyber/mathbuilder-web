# MathBuilder — веб-версия (GitHub Pages)

Веб-аналог приложения LEGO Education MoreToMath MathBuilder с полной русификацией.

## Что сделано
- Главное меню / Лобби уроков с 16 активностями
- Перевод интерфейса на русский и английский
- Текст всех заданий активностей переведён на русский
- Переключатель языков (RU / EN)
- Адаптивная вёрстка

## Структура
```
mathbuilder-web/
├── index.html          # Главная страница
├── css/
│   └── style.css       # Стили
├── js/
│   ├── translations.js # Все переводы (интерфейс + задания)
│   └── app.js          # Логика приложения
└── README.md
```

## Размещение на GitHub Pages

### 1. Создайте репозиторий на GitHub
Зайдите на [github.com](https://github.com) и создайте новый репозиторий, например `mathbuilder-web`.

### 2. Загрузите файлы
Скопируйте всё содержимое папки `mathbuilder-web/` в репозиторий (через веб-интерфейс GitHub или `git push`).

### 3. Включите GitHub Pages
В настройках репозитория (Settings → Pages):
- **Source:** Deploy from a branch
- **Branch:** `main` (или `master`), папка `/ (root)`
- Нажмите Save

Сайт будет доступен по адресу: `https://<ваш-аккаунт>.github.io/mathbuilder-web/`

## Разработка
Для локального тестирования просто откройте `index.html` в браузере.

## Ограничения
Это упрощённая веб-версия. 3D-строительство из кирпичиков (как в Unity-оригинале) требует Three.js или аналогичного движка и будет добавлено в следующих версиях.
